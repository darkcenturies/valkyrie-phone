# Contributing

Contributions are welcome. Every change goes through a pull request and is
reviewed by the maintainer (@darkcenturies) before it is merged.

1. Fork the repository and make a branch for your change.
2. Build it (`valkyrie-asi-suite\build.ps1`) and try it in the game.
3. Open a pull request saying what it changes and how you tested it, with a
   screenshot or the log (`valkyrie-phone.log`) where it helps.

Keep to what is already here:

- Write code that reads like the code around it.
- Do not add game files, or anything made from them (textures, models,
  sounds, map tiles, websites). The phone reads those from the player's own
  game at run time.
- Do not add other projects' logos or artwork without their permission.
- Contributions are accepted under this repository's BSD 3-Clause licence.
